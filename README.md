# Геометрические методы в физике

Электронное пособие и справочник по теоретической физике бакалавриата на
геометрическом языке (дифференциальные формы, группы Ли, симплектическая
геометрия, связности) с исполняемым кодом на Python.

## Устройство репозитория

| Путь | Что там |
|---|---|
| `topics.yml` | **карта тем**: все темы пособия, курс, зависимости, содержание |
| `math/`, `physics/` | статьи (`.qmd`): ось «аппарат» и ось «физические курсы» |
| `conventions.qmd` | единые обозначения и соглашения о знаках |
| `src/gmph/` | вычислительное ядро: общие функции для статей |
| `tests/` | тесты ядра, конвенций и карты тем |
| `scripts/topics.py` | сборка карты тем и проверка зависимостей |
| `filters/topics.lua` | блок «Уровень и связи» в начале каждой статьи |
| `_macros.html` | общие LaTeX-макросы (`\dd`, `\hodge`, `\iprod`, …) |
| `notes/` | личные черновики (не публикуются, в `.gitignore`) |

## Как работать

```bash
conda env create -f environment.yml   # один раз
conda activate gmph
python -m pytest                      # тесты ядра
quarto preview                        # сайт с автообновлением в браузере
quarto render                         # полная сборка в _site/
```

## Новая статья

Все темы, их курс и зависимости перечислены в `topics.yml`. Статья темы
кладётся в каталог её раздела (например, тема `hodge-star` раздела
`math/forms` — в `math/forms/hodge-star.qmd`) и указывает в заголовке
только идентификатор темы:

```yaml
---
title: "Оператор Ходжа на многообразии"
topic: hodge-star   # идентификатор из topics.yml
order: 7            # порядок в оглавлении раздела
---
```

Курс и зависимости в статье не повторяются: они берутся из `topics.yml`.
Новая тема сначала добавляется туда.

Сборка остановится, если:
- тема ссылается на несуществующую тему или зависит от темы более старшего курса;
- в зависимостях есть цикл;
- статья лежит не в каталоге своего раздела или её темы нет в `topics.yml`;
- код в статье завершился с ошибкой.

Функции, нужные в нескольких статьях, добавляются в `src/gmph/` вместе с тестами.
